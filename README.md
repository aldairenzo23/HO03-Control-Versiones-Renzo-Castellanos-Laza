# HO03 - Control de Versiones

## 1. Descripción del caso práctico

Este caso práctico aborda la implementación básica del control de versiones en el flujo de desarrollo de proyectos tecnológicos
empleando la combinación de Git y GitHub.
El trabajo consiste en la creación de un repositorio de acceso público diseñado para estructurar los activos del proyecto (código fuente, documentos de arquitectura y especificaciones). A lo largo de la actividad, se llevarán a cabo las operaciones esenciales del control de código:
**Rastreo de cambios:** Seguimiento continuo de modificaciones en archivos individuales y colectivos.
**Generación de puntos de restauración:** Creación de confirmaciones periódicas (commits) con mensajes explicativos estandarizados.
**Sincronización remota:** Publicación del historial local hacia GitHub (push) para garantizar el respaldo en la nube y la visibilidad del repositorio.

Con ello, se consolida la capacidad de gestionar proyectos con estándares de orden, transparencia y mantenibilidad en el tiempo.

## 2. Objetivo del repositorio
El objetivo principal de este repositorio es demostrar la aplicación práctica de las funcionalidades básicas de GitHub en la gestión, organización y documentación de proyectos tecnológicos.
Específicamente, este repositorio busca:
**Organizar la estructura de archivos:** Establecer una jerarquía clara de directorios y recursos para facilitar la navegabilidad y el mantenimiento del proyecto.
**Documentar el proyecto:** Utilizar el archivo README.md redactado en sintaxis Markdown como la portada principal, detallando el propósito del repositorio, las instrucciones de uso y el contexto general.
**Aplicar buenas prácticas de Git:** Implementar un flujo de trabajo ordenado mediante mensajes de commit descriptivos, un registro cronológico de cambios y la correcta sincronización entre el entorno local y el entorno remoto en la nube.
